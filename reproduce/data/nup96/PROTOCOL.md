# Direct triple correlation on public Nup96 catalogues

The analysis uses the complete deposited Reinhardt and Zaza four-round
Nup96 center catalogues, and the 100 previously examined Reinhardt
localization-template pairs (seeds 987000 through 987099). Use every
row, the recorded code, 30 nm radius, and the same observed coordinate
rectangle as Crosslabel. Keep source picking and processing explicit.
Both observed catalogues are descriptive, with no library decision.

## Scores

Implement the coordinate enumeration of the direct triple correlation
in [Yin et al., Eq. 1](https://doi.org/10.1038/s41467-018-08048-2),
integrated over the configurations where both neighbors lie within
30 nm of the anchor. Average over ordered distinct code triples with
weights proportional to the product of their record counts. Compute
the rectangular translation correction for each ordered star using the
joint overlap of the three translated windows. The integral is
normalized by the squared disc area. This is an independent integrated
adaptation of the published statistic. The upstream Windows MATLAB
executables compute a full geometry profile and use an angular edge
correction. The scalar and its reference cutoff are specific to this
comparison.
[Upstream implementation](https://github.com/yiny02/direct-Triple-Correlation-Algorithm)

For displacement vectors u,v from the anchor, the joint overlap
fraction is the product over axes of one minus the span of {0,u,v}
divided by the rectangle width along that axis. Inverse overlap
weights enter the count. Let A be rectangle area, D disc area and P
the total product of record counts over ordered distinct codes.
Multiply the weighted ordered star count by A²/(D² P) for raw g3.

The connected comparator subtracts the two integrated anchor-neighbor
pair correlations and the integrated neighbor-neighbor correlation
and adds two. Use the same code weights and rectangular translation
correction for pairs. The first two terms use the disc kernel and the
last uses the overlap area of two radius-30 discs out to 60 nm. This
matches the integration of g3 - g12 - g13 - g23 + 2. Report the
dimensionless score and its descriptive conversion to a per-anchor
contrast, (N D/A)²/2 times the score. Local annulus compensation and
pair covariance estimation distinguish the Crosslabel estimator.

## Evaluation

Compute four separately ranked scores on the same fields: raw and
connected triple correlation, Crosslabel point, and Crosslabel lower
endpoint. The Crosslabel point score helps separate the choice of
estimator from the effect of using its model interval in the ranking.
Use one reference bank of 99 independent two-code template fields
(seeds 988000 through 988098), generated by the prior paired generator
from the same measured template bank. Use a fixed inclusive upper-tail
rank threshold of .05 for all scores. Match observed-versus-reference
geometry by the same bounding rectangle rule. Any unsupported
reference blocks the calibrated analysis. Preserve any unsupported
evaluation result.

Use the archived Crosslabel scores for the 200 prior evaluation fields.
Regenerate those fields with the pinned generator and check seed, row
count, per-code counts, model window, template count and within-template
witness tally against the saved records. Replay the Crosslabel scores
for the first pair to check numerical identity. Report both cohorts,
exact binomial intervals conditional on the reference bank, within-pair
score ordering, and paired decision disagreements with Crosslabel's
lower-endpoint rule. All template fields are conditional on a single
measured template bank. The alternative changes code occupancy and
may change lower-order summaries as well. The test compares operating
points under that constructed observation law.

Use one local worker and a 15-minute collection limit. Preserve
all scores, checks, and input hashes. Use no new CD20 outcomes.

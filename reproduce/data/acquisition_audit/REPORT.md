These are selected cluster centres, not certified one-protein records. The16 G5M input files have container identity checked here; G5M map arrays lack the constituent n column in this retained roster.
- The cell4_3D molecule maps retain z, but the declared analysis uses x/y projection; raw compact_locs does not retain z. A projected30nm target is not a three-dimensional30nm physical-neighborhood target. No new z selection was made.
